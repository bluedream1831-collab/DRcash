雞大人的試算工具箱｜重新整理版（2026-10-20）

內容：index.html、assets 內的圖片、網站運作說明。
全部功能在瀏覽器本機運算；無外部腳本、無上傳試算內容功能。

本版保留：
- 400 萬與 1000 萬快捷試算與可自訂投入額
- 預設 8% 年配息率（可自行調整）
- 配息型：累積型比例 7:3、8:2、9:1
- 無房貸新申貸、原貸增貸／轉貸、地政與文件指南
- 雞大人與發財雞的圖片、繁體中文文字
- 「一切以實際流程、承辦金融機構核貸條件及主管機關規定為準」

發布方法：
1. 先用 Windows Defender 掃描下載的 ZIP。
2. 防毒顯示沒有威脅後，解壓縮。
3. 把 index.html 與 assets 整個資料夾上傳到 DRcash 儲存庫的 GitHub Pages 發布目錄。
4. 等待 GitHub Pages 部署完成後刷新網頁（必要時強制重新整理）。
5. 不要只上傳 index.html，否則圖片會遺失。

安全提醒：
本版經過 HTML 靜態檢查、圖片重新編碼與瀏覽器功能測試，
但這不等同 Windows Defender 或其他防毒引擎的惡意程式掃描。
若下載時仍顯示「系統偵測到病毒」，請不要選擇保留或略過警告；
請提供「Windows 安全性 > 病毒與威脅防護 > 保護歷程記錄」中的威脅名稱供進一步排查。
